# Setup

Use Node.js 24 and the pnpm version pinned in `package.json`. Build the checkout before configuring an agent. The MCP command is `node` with the absolute path to `dist/cli.js`, followed by `mcp`.

The default browser channel is Microsoft Edge. Enable remote debugging in `edge://inspect/#remote-debugging`. Browser Bridge attaches to the running browser and does not launch a separate profile.

Runtime state and credentials belong under `%LOCALAPPDATA%\BrowserBridge` on Windows. Use `BROWSER_BRIDGE_HOME` for an isolated configuration in tests. Never commit that directory.

The extension is loaded unpacked from the built `dist/extension` directory. Its Native Messaging registration and agent configuration are generated by the setup command.
